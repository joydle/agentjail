One jail is one child process inside these layers, outermost first.

Isolation layers

One jail is one child process. Each layer is put in place in the child between fork and execve, in this order. No VM, no daemon, no setuid helper.

  1. cgroup v2

    Memory, CPU, PID and disk I/O limits. The child blocks on a barrier pipe until the parent has moved it into its cgroup, so there is no unconstrained start-up window.

    memory.max · cpu.max · pids.max · io.max

  2. Namespaces

    A user namespace (on by default) plus fresh mount, network and IPC namespaces, and a PID namespace through a double fork with a masked /proc mounted inside it. The jailed process never runs as host root: its root maps to an unprivileged host id, or it drops to nobody when user namespaces are off.

    unshare(NEWUSER) → unshare(NEWNS|NEWNET|NEWIPC) → NEWPID

  3. Filesystem

    pivot_root into a private, read-only tmpfs root at a 128-bit random path; the old root is detached. /bin, /lib, /usr bind read-only, /etc is a tmpfs with a short allowlist, /tmp is noexec. Source is read-only at /workspace, output writable at /output.

    pivot_root · umount2(MNT_DETACH)

  4. Landlock

    Filesystem access rules on top of the mount layout, applied after pivot_root and on by default (Linux 5.13 and newer): read and execute on system paths, write only to /tmp and /output, nothing else. Jail::new refuses to start if the kernel can't enforce it.

    landlock_restrict_self

  5. Privileges

    No new privileges, every inherited descriptor marked close-on-exec, the bounding set dropped, securebits locked, and every capability zeroed in the process that will exec.

    PR_SET_NO_NEW_PRIVS · close_range · capset(0)

  6. Seccomp

    A BPF blocklist, Standard or Strict, compiled once per Jail and installed last before execve. It kills x32 and foreign-architecture syscalls, blocks unshare, setns, clone with any CLONE_NEW* flag, mount, module, keyring, BPF, perf, io_uring, ptrace and more, answers clone3 with ENOSYS, and filters TIOCSTI and raw socket families by argument.

    seccompiler · SECCOMP_RET_ERRNO

  7. Network

    None, Loopback or Allowlist. An allowlist routes through an in-process CONNECT proxy over a veth pair: the host name is checked, resolved once, private and loopback addresses are dropped, and the proxy dials the IP it approved, on port 443 unless you allow more. Each proxy serves only its own jail, with caps on connections, header size and idle time. An nftables table keeps jails away from host services and from each other.

    veth over netlink · CONNECT :443 · nft

Use

A library first. Build a Jail from a config or a preset, then run or spawn commands in it.

use agentjail::{Jail, preset_build};

#[tokio::main]
async fn main() -> agentjail::Result<()> {
    // user namespace, Landlock and seccomp are on by default
    let jail = Jail::new(preset_build("./src", "./out"))?;
    let out  = jail.run("/usr/bin/npm", &["run", "build"]).await?;
    println!("exit={} oom={} timeout={}", out.exit_code, out.oom_killed, out.timed_out);
    Ok(())
}

./src is mounted read-only at /workspace, ./out read-write at /output. The build preset has no network and uses the Strict seccomp level.

use agentjail::{Jail, JailConfig, Network, SeccompLevel};

let jail = Jail::new(JailConfig {
    source:        "/code".into(),       // ro at /workspace
    output:        "/artifacts".into(),  // rw at /output
    network:       Network::None,
    seccomp:       SeccompLevel::Standard,
    memory_mb:     Some(512),         // None = no limit
    cpu_percent:   100,                  // 100 = one core
    max_pids:      64,
    io_read_mbps:  100,
    io_write_mbps: 50,
    timeout_secs:  300,
    ..Default::default()
})?;

Defaults: PID and IPC namespaces, Standard seccomp, no network, 512 MB, 64 PIDs, 300 s. user_namespace and landlock default to on; stdin is /dev/null unless inherit_stdin. Forks run on an internal process-lifetime thread, so a jail dies with the embedder process, not the calling thread.

Network::Allowlist(vec![
    "api.anthropic.com".into(),
    "registry.npmjs.org".into(),
    "*.mcp.example.com".into(),
])

// or the install preset, which requires explicit domains
preset_install("./src", "./out", vec!["registry.npmjs.org".into()])

The proxy checks the host against the list, resolves it once, drops private, loopback, link-local and CGNAT addresses, and dials what is left. TLS passes through untouched. Needs CAP_NET_ADMIN for the veth pair.

use agentjail::{events, JailEvent};

let handle = jail.spawn("/usr/bin/npm", &["run", "build"])?;
if let Some(s) = handle.stats() {
    println!("mem {} B  pids {}", s.memory_current_bytes, s.pids_current);
}

let (tx, mut rx) = events::channel();
tokio::spawn(async move {
    while let Some(ev) = rx.recv().await {
        match ev {
            JailEvent::Stdout(l) => println!("{l}"),
            JailEvent::OomKilled => eprintln!("OOM"),
            _ => {}
        }
    }
});
let out = handle.wait_with_events(tx).await?;

Output is capped at 256 MiB per stream, so a chatty child cannot exhaust the parent.

use agentjail::Snapshot;

let snap = Snapshot::create(&output, &snapshot_dir)?;
snap.restore()?;

// branch a running jail: reflink (FICLONE) where the filesystem supports it,
// a plain copy otherwise; the source is frozen only for the clone
let handle = jail.spawn("/usr/bin/python3", &["train.py"])?;
let (forked, _info) = jail.live_fork(Some(&handle), "/tmp/fork-out")?;

Incremental snapshots store file bodies by BLAKE3 hash in a shared pool. Restore skips symlinks, strips setuid and setgid bits, and rejects absolute or .. paths in a manifest.

Presets

Starting points for common jobs. Each returns a JailConfig you can adjust.

presetnetworkseccompmemorypidstimeout
preset_buildNoneStrict512 MB128600 s

preset_agentNoneStandard256 MB32300 s
preset_devLoopbackStandard1 GB2563600 s
preset_gpuNoneStandard8 GB2563600 s

preset_gpu passes NVIDIA devices into the jail and exposes the GPU driver's attack surface: use it for trusted workloads only.

Threat model

What a jailed process tries, what stops it, and the regression test that fails if the protection ever does.

  • Read ~/.ssh or ~/.aws

    Never mounted: the jail sees a minimal root, not the host.

    test_cannot_read_ssh_keys

  • Exfiltrate over the network

    Own network namespace; only allowlisted hosts through the proxy.

    test_reverse_shell_blocked

  • Fork bomb

    pids.max in the jail's cgroup.

    test_pid_limit_blocks_fork_bomb

  • Signal host processes

    Separate PID namespace with its own /proc.

    test_pid_namespace_full_sandbox

  • Escape through a namespace

    unshare, setns and namespace-creating clone are blocked by seccomp; clone3 gets ENOSYS.

    test_seccomp_blocks_unshare

  • Bypass seccomp with io_uring

    The io_uring_* syscalls are blocked.

    seccomp_standard_blocks_documented_syscalls

  • Write, then execute from /tmp

    /tmp is a noexec tmpfs.

    test_tmp_noexec

  • Escape through a symlink

    Snapshots, forks and cleanup skip symlinks rather than follow them.

    test_snapshot_restore_does_not_follow_symlinks

Requirements and limits

What it needs, and what it does not protect you from.

Beta. The core crate, crates/agentjail, is the load-bearing piece. Isolation is on by default, but the seccomp filter is a blocklist and the host firewall needs nft: treat a jail as one layer of defence and run hostile code on a VM or a disposable host. The control plane, SDKs, web UI and gateway are useful, but their APIs may move before 1.0.

Linux 5.13 or newer
With cgroup v2 and Landlock. Linux only; the embedder runs as root for cgroups and networking, the jail never does.
Not a VM
A kernel exploit escapes. For a stronger boundary, run it inside gVisor or a Firecracker microVM.
Rust 1.88 or newer
Edition 2024, with tokio.
Allowlist costs a veth
One veth pair per concurrent jail in Allowlist mode.
CAP_NET_ADMIN
Only for Allowlist networking, to create the veth pair over netlink; nft installs the host firewall.
GPU widens the surface
GPU mode exposes the NVIDIA kernel driver to the jailed process.

There is also an optional control plane, agentjail-server: phantom credentials that keep real API keys out of the jail, persistent workspaces, snapshots, an audit feed, and Node and Python SDKs. See the README.
